บันทึกเวรที่ "จัด" กับเวรที่ "อยู่จริง" แล้วให้ระบบสรุปยอดต้องจ่ายและค่า ontop ให้อัตโนมัติ

ตารางเวร

คลิกที่ช่องเพื่อวนค่า: ว่าง → ½ → 1 → 1½ → ว่าง

🖼️ คลิกตรงนี้ เพื่อเลือกไฟล์ตารางเวร หรือกด Ctrl+V เพื่อวางรูปได้จากทุกที่
ระบบจะใช้ AI อ่านภาพและเติมข้อมูลลงในตารางให้ทันที
ข้อมูลจะถูกเติมลงแท็บ เวรตามจัด พร้อมอ่านตารางเวร
ว่าง (0) ครึ่งเวร (0.5) เต็มเวร (1) เวรครึ่ง+ (1.5)

กรณีพิเศษ: เพ็ญแทนกิ้ม/แปง

ระบบตรวจพบว่า "เพ็ญ" อยู่เวรแทน "กิ้ม" หรือ "แปง" ในวันเดียวกัน จะไม่คิดค่า ontop และหักลดยอดจ่ายชดเชยออก

วันที่ อยู่แทน กะ (ช่อง) หัก Ontop (เพ็ญ) ลดยอดจ่ายชดเชย

สรุปยอด

อยู่จริงกี่ช่อง เทียบกับที่จัดไว้ → ต้องจ่าย/ได้รับสุทธิ พร้อมค่า ontop ที่ได้จากเวรที่อยู่จริง

ชื่อ รวมที่จัด รวมอยู่จริง ผลต่าง (ช่อง) ยอดสุทธิ ontop (จากอยู่จริง)
รวมทั้งหมด 0 0 0 0 0

สรุปยอดแยกกลุ่ม

เพ็ญ + หลิว + แนน (ได้รับสุทธิรวม) 0฿
ยอดรวมที่ต้องจ่ายชดเชย (จากทุกคนที่ขาดเวร) 0฿

ยอดสุทธิ คำนวณจากอัตรากลาง 0.5 = 150฿ · 1 = 300฿ · 1.5 = 450฿ (ตามช่องที่จัด ลบ ช่องที่อยู่จริง) — ถ้าเป็น ต้องจ่าย แปลว่าจัดเวรไว้แต่มีคนอื่นอยู่แทน ต้องจ่ายชดเชยให้คนที่อยู่แทน ถ้าเป็น ได้รับ แปลว่าอยู่เวรเกินกว่าที่จัดไว้ ควรได้รับเงินชดเชย
ontop คือยอดเงินที่ รพ. จ่ายให้ตามช่องที่ "อยู่จริง" จริง ๆ ตามอัตรา 0.5 = 480฿ · 1 = 1,000฿ · 1.5 = 1,480฿
