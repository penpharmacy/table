สรุปยอด

อยู่จริงกี่ช่อง เทียบกับที่จัดไว้ → ต้องจ่าย/ได้รับสุทธิ พร้อมค่า ontop ที่ได้จากเวรที่อยู่จริง

ชื่อ รวมที่จัด รวมอยู่จริง ผลต่าง (ช่อง) ontop (ก่อนหัก) ontop (สุทธิ) OT
รวมทั้งหมด 0 0 0 0 0 0

สรุปยอดแยกกลุ่ม

เพ็ญ + หลิว + แนน (ได้รับสุทธิรวม) 0฿
ยอดรวมที่ต้องจ่ายชดเชย (จากทุกคนที่ขาดเวร) 0฿

ONTOP คำนวณจากอัตรากลาง 0.5 = 150฿ · 1 = 300฿ · 1.5 = 450฿ (ตามช่องที่จัด ลบ ช่องที่อยู่จริง) — ถ้าเป็น ต้องจ่าย แปลว่าจัดเวรไว้แต่มีคนอื่นอยู่แทน ต้องจ่ายชดเชยให้คนที่อยู่แทน ถ้าเป็น ได้รับ แปลว่าอยู่เวรเกินกว่าที่จัดไว้ ควรได้รับเงินชดเชย
OT คือยอดเงินที่ รพ. จ่ายให้ตามช่องที่ "อยู่จริง" จริง ๆ ตามอัตรา 0.5 = 480฿ · 1 = 1,000฿ · 1.5 = 1,480฿
